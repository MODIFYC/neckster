# 🐹 Neckster

거북목이 될수록 목이 늘어나는 햄스터 Chrome 확장 프로그램

## 📌 소개

**Neckster**는 장시간 웹서핑하는 동안 점점 '거북목'이 되는 모습을 재미있게 시각화하는 Chrome 확장 프로그램입니다. 모든 웹페이지에서 귀여운 3D 햄스터가 당신의 화면 우측 하단에 나타나 시간이 지날수록 목이 길어집니다.

## ✨ 주요 기능

- **목 늘어나는 애니메이션**: 30초마다 목이 0.1씩 길어집니다
- **거북목 자세**: 목이 길어질수록 햄스터가 앞으로 구부러지는 거북목 자세를 취합니다
- **상호작용**: 햄스터를 클릭하면 하트 이모지가 떠오릅니다 ❤️
- **자동 걷기**: 5~10초 주기로 자동으로 걷습니다
- **생생한 호흡**: 살아있는 느낌을 주는 호흡 애니메이션
- **반응형**: 브라우저 창 크기 변경에 자동으로 대응
- **시간 추적**: 백그라운드에서 누적된 시간을 기록합니다

## 🎯 기술 스택

- **Three.js**: 3D 렌더링 엔진
- **GLTFLoader**: 3D 모델 로딩
- **Chrome Extension Manifest V3**: 확장 프로그램 기반

## 🚀 설치 방법

1. 이 저장소를 클론하거나 다운로드합니다
   ```bash
   git clone <repository-url>
   ```

2. Chrome 브라우저를 엽니다

3. 주소창에 `chrome://extensions/`를 입력합니다

4. 우측 상단의 **개발자 모드**를 켭니다

5. **확장 프로그램 압축해제 로드** 버튼을 클릭합니다

6. 이 프로젝트의 폴더를 선택합니다

7. Neckster 확장 프로그램이 설치됩니다! 🎉

## 📁 프로젝트 구조

```
neckster/
├── manifest.json         # 확장 프로그램 설정
├── content.js           # 메인 콘텐츠 스크립트 (3D 렌더링)
├── background.js        # 백그라운드 스크립트 (시간 추적)
├── assets/
│   └── hamster.glb      # 3D 햄스터 모델
├── libs/
│   ├── three.min.js     # Three.js 라이브러리
│   └── GLTFLoader.js    # GLTF 모델 로더
├── icons/
│   ├── icon16.png       # 16x16 아이콘
│   ├── icon48.png       # 48x48 아이콘
│   └── icon128.png      # 128x128 아이콘
└── README.md
```

## 🎮 사용 방법

1. 확장 프로그램을 설치하면 모든 웹페이지의 우측 하단에 햄스터가 나타납니다

2. **그냥 두기**: 시간이 지날수록 목이 자동으로 길어집니다

3. **클릭하기**: 햄스터를 클릭하면 하트가 떠오르고 몸이 찌그러졌다가 돌아옵니다

4. **감상하기**: 귀여운 걷기 애니메이션과 호흡을 즐깁니다

## 🔧 개발 정보

### 주요 파일 설명

**content.js**
- Three.js로 3D 렌더링 담당
- 캔버스를 생성하고 햄스터 모델 로드
- 애니메이션 루프 실행
- 클릭 이벤트 처리

**background.js**
- Chrome Alarms API를 사용해 1분마다 시간 추적
- LocalStorage에 누적 시간 저장

### 핵심 애니메이션

- **목 늘어나기**: Neck 보드의 scale.y를 증가
- **거북목 각도**: Head와 Neck의 rotation.x를 조정
- **호흡**: 전체 모델의 scale을 사인파로 변동
- **걷기**: 다리 애니메이션과 좌우 이동

## 🐛 알려진 문제

- 일부 무거운 웹페이지에서 성능 저하가 있을 수 있습니다
- iframe 내부의 콘텐츠에는 햄스터가 나타나지 않습니다
